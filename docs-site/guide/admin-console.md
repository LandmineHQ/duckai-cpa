# 管理控制台

管理控制台是网关的完整控制面，和 API 共用同一个进程，默认地址：

```text
http://127.0.0.1:8787/admin/
```

使用启动时打印的 **adminToken** 登录。adminToken 与 API Key 是两套凭据：

- adminToken：只能访问 `/admin/api/*`；
- API Key：只能访问 `/v1/*`。

![管理后台概览](/assets/admin-overview.jpg)

## 页面导航

| 页面 | 你要做的事 |
| --- | --- |
| 概览 | 查看上游健康、队列/RPS、请求统计、token 用量、模型目录与最近日志 |
| 连接测试 | 在后台直接与模型对话，验证流式、图片、思考、工具与压缩 |
| 默认身份 | 查看/配置网关默认身份的 journeyId、指纹、设备信息；不要随意轮换 |
| 身份池 | 管理匿名分身：创建、启用、旋转密钥、删除、查看额度与绑定 |
| 订阅 | 捕获 DuckDuckGo 登录 token、绑定身份、配置 refresh token 自动续期 |
| 会话历史 | 只读查看 `/v1` 与连接测试历史：工具调用、图片、reasoning、来源 |
| 日志 | 按上游/管理 API 分离的请求日志；支持筛选、分页、下载 |
| 代理 | 配置 HTTP/HTTPS/SOCKS 代理并测试出口 IP |
| 设置 | 上游、队列、上下文、压缩、提示词、日志保留等配置 |
| 模型配置 | 按模型覆盖上下文/输入/输出限制与推理等级 |
| API Key | 创建、吊销、查看（脱敏）API Key |
| 示例 | 常见客户端/curl/代码片段 |

## 概览

第一行是自动刷新控制条（关闭 / 5s / 10s / 30s / 60s + 手动刷新）。下面依次是：

- 上游健康、挑战是否正常、代理模式；
- 队列：执行中、排队、RPS、最大并发；
- 请求统计与成功率；
- token 用量（按模型、按身份 × 模型）；
- 模型目录与当前能力；
- 最近日志。

## 连接测试

连接测试是排查上游问题最快的入口：

- 支持选择模型、reasoning effort、联网搜索、图片生成；
- 以 SSE 流式渲染 reasoning、正文、来源、图片与工具调用；
- 会话消息保存在 `test_sessions`，可以继续、重试或手动压缩；
- 「会话历史」页面会复用同一套消息组件展示。

> 连接测试的图片/工具消息与真实 `/v1` 请求共享同一套会话语义；调试压缩、PDF、图片上下文时优先在这里复现。

## 身份池

每个身份包含独立的：

- `journeyId`、设备指纹、deviceId；
- durable stream 密钥与 RSA 密钥；
- 每身份 RPS=1 的队列；
- 订阅绑定与额度冷却状态。

常用操作：

- **创建**：生成新匿名身份；受池上限限制；
- **启用/停用**：停用后不参与路由；
- **旋转**：重新生成密钥，已有会话可能需要新 epoch；
- **删除**：被订阅绑定或当前 active 时会被拒绝，必要时先解绑。

> 默认身份 `id_default` 是持久身份，不应随意删除或轮换；它会直接影响 duck.ai 侧的身份稳定性。

## 订阅

订阅页负责把 DuckDuckGo 登录态带入网关：

1. 在已登录 duck.ai 的浏览器中运行书签脚本/Console 脚本；
2. 通过同源接口捕获 token，回传到管理台；
3. 创建订阅实体并绑定身份；
4. 可选：粘贴 `ddg_auth_refresh_token` 开启自动续期。

详见 [订阅与身份](/guide/subscriptions)。

## 会话历史

历史页只读展示：

- 用户/助手消息、工具调用、生成图片、reasoning、来源；
- 注入的客户端工具协议、真实 upstream messages（脱敏）；
- 连接测试会话与 `/v1` 会话；
- 支持多选批量删除。

## 日志与用量

- 上游日志与管理 API 日志分开展示；
- 每条上游日志带 `sessionKey`、`identityId`、`requestId`，可与会话/身份对照；
- token 用量是估算口径（字符/tokenizer），清空日志不会清空累计统计；
- 支持保留条数与天数配置、日志下载。

## 代理与 IP 脱敏

代理页可配置 HTTP/HTTPS/SOCKS 代理，并测试出口 IP。

> 代理出口 IP 等敏感地址在控制台默认使用脱敏组件展示（例如 `70.***.***.***`），点击眼睛图标才显示真实值。新增 IP 展示时也应使用 `MaskedIp`，避免截图泄露。

## 模型配置

模型配置页按模型覆盖：

- 上下文窗口字符数；
- 单条输入上限；
- 输出 token 估算；
- 推理等级。

保存是防抖自动保存，不需要点“保存”按钮；底部“危险/高级操作”包含静默清理与重置全部。

## 安全建议

- 管理台只监听内网/回环，或放在带认证的反向代理后；
- 不要截图包含真实 IP、token、API Key、恢复码；
- 定期备份 `data/`，但不要提交到仓库；
- 升级前阅读 release notes 与 `docs/ACCEPTANCE.md`。
